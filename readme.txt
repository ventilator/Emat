Mit diesem Programm können Sie einfach Ihre Mp3-Sammlung ausmisten, ohne von Fehlermeldungen,
Bestätigungen und sonstigen Fenstern genervt zu werden.
Bei einem Fehler sollte der Windows-Fehlerton ertönen, sonst gibt es keine Meldungen.
Achtung:
Alle Aktionen wirken sich meist sofort aus.
Seien Sie deshalb besonders vorsichtig mit der Löschfunktion; ES GIBT KEINEN PAPIERKORB
Glauben Sie deshalb an die Macht von Undelete-Tools.
Für Schäden haften Sie selbst.

| Return im Quellordnereingabefeld: Ordner durchsuchen
| Doppelklick auf Listeneintrag: Abspielen
| Rechte Maustaste auf Listeneintrag: Umbennen
| Entf auf Listeneintrat: Datei löschen
| Klick  auf Listeneintrag: Spulen
| m/M/anfügen: zur Datei zur Mp3-Player-Liste anfügen
